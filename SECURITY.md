# Security Policy

## Reporting a Vulnerability

Do not open a public issue for suspected vulnerabilities.

Email security reports to security@chaterface.com with:

- Affected component or endpoint.
- Steps to reproduce.
- Impact and any known exploitability constraints.
- Suggested fix, if available.

We will acknowledge receipt within 3 business days and follow up with a remediation plan or request for more detail.

## Supported Versions

Security fixes are applied to the default branch before public release. After public release, supported versions will be documented here as release branches are created.
